## 何时使用

`ModelTraining` 用自动循环的五个步骤说明模型如何学习。一个批次离开训练数据堆，落入画在分层底板上的小型网络的输入层。信号沿每条连线向前传递，得到预测，
输出层旁的两个类别概率随之更新。接着误差以一小段短线沿连线向后传回，它经过的每条连线都会变强一点。在各个轮次（epoch）中，批次接连流过：有用的连线变粗并
染上强调色，其余连线保持浅淡；网络旁的损失曲线逐步下降，损失和轮次读数同步计数。最后，留出数据在训练好的模型中跑一遍，分数向上计数，评估达到（或未达到）
目标。其中的网络和数字都是示意性的。

- **AI 产品的落地页**：一眼看懂训练、微调或评估。
- **文档与课程**：介绍批次、轮次、损失曲线和留出评估。
- **演讲**：不需要旁白，整个故事约二十秒讲完。

## 何时不用

- **真实的训练指标**：插图播放的是自己的故事。实测损失请用 `LineChart` 绘制，实时任务请用 `TrainingRun` 展示。
- **数据管道**：记录在系统中流转时请用 `DataFlow`。
- **可能被当作基准成绩的数字**：在插图旁注明它们只是示例。

## 用法

插图不需要任何数据：它训练一个猫狗照片分类器，共十二个轮次，在 90% 的目标下得到 94.2% 的分数。

```xml

```

### 五个步骤

| 步骤 | 发生的事 |
|---|---|
| Batch | 一张数据页离开训练数据，落入输入层，输入层随之点亮 |
| Forward pass | 信号沿每条连线逐层传递；类别概率随之更新 |
| Backward pass | 误差沿连线传回；它经过的每条连线都变强一点，损失沿曲线下移 |
| Epochs | 批次接连流过；有用的连线变粗，损失下降，轮次向上计数 |
| Evaluate | 留出数据跑一遍；分数向上计数，对勾变绿 |

图下方的步骤栏可以播放、暂停故事，也可以跳到任一步骤：故事播放时从该步骤继续，暂停时显示该步骤的静止画面。`GoToStep` 在代码中做同样的事，
`CurrentStep` 表示当前步骤。`Phase`、`Iteration` 和 `CurrentLoss` 跟随运行进度，每次权重更新后会触发 `IterationCompleted`，附带该步骤及其损失。

### 你自己的任务

`ClassNames`、`InputCount`、`HiddenUnits`、`Samples`、`HeldOutSamples`、`BatchSize`、`Epochs`、`LossFrom`、`LossTo`、`Accuracy` 和 `Target`
描述任务；`LossValues` 用均匀分布在整个运行过程中的实测值替换曲线。`StepCount` 设置故事展示多少个批次，`Labels` 保存所有文字，包括一个样本是什么
（`Unit`）。下面的示例训练一个垃圾邮件过滤器，它没有达到目标，因此评估以低于目标结束。

<Demo name="OwnLosses" />

```csharp
card.ClassNames = ["Spam", "Inbox"];
card.Labels = new ModelTrainingLabels { Unit = "emails" };
card.LossValues = [1.12, 0.71, 0.52, 0.44, 0.4, 0.38, 0.37];
card.IterationCompleted += (_, e) => log.Add($"{e.Iteration}: {e.Loss:0.00}");
```

设置 `DefaultStep` 可在故事播放前显示某个步骤（并从那里开始播放），`AreControlsVisible` 隐藏步骤栏，`IsCaptionVisible` 隐藏说明文字，`Accent`
为信号、学到的连线、曲线和当前步骤着色。

## 无障碍

- 插图是一个以 `Title`（"Model training"）命名的组；图示是一张图像，其名称根据类别和数字描述整个运行过程。设置 `Description` 可自行措辞。
- 步骤栏是一组按钮，名称如 "Step 3 of 5: Backward pass"；播放按钮名为 Play 或 Pause。
- 说明文字用文字复述当前步骤；读者选择步骤或逐步浏览故事时，一个礼貌的实时区域会朗读它。
- 不只依赖颜色：每个读数都是数字，评估会显示 Pending、Scoring、Passed 或 Below target，领先的类别显示其概率。

## 动效

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 批次 | 数据页沿弧线飞入输入层，数据堆随之上移 | 静止画面 | 静止画面 |
| 前向与反向传递 | 圆点沿连线向前，短线沿连线向后；单元点亮并泛起圆环 | 静止画面 | 静止画面 |
| 权重与损失 | 误差经过时连线变粗；损失点沿曲线滑动 | 静止画面 | 静止画面 |
| 评估 | 分数向上计数；标签交叉淡入并从 0.92 缩放到位 | 立即显示 | 立即显示 |
| 悬停 | 鼠标停在数据堆或某一层上时，故事以弹簧方式减速到 0.6× | 无变化 | 无变化 |

速度为 1 时一次运行约 21 秒，并无缝循环：开头的 0.8 秒把训练好的模型还原成未训练的样子。一切都是故事时钟的函数，因此会随 `Speed` 暂停、单步和缩放。
在减弱动效下，插图直接打开已完成的运行，也没有播放按钮；选择一个步骤会显示它的静止画面。

## 响应式

- 从 720 px 起，读数和损失图表以 232 px 宽的一列立在网络旁边；更窄时位于网络下方。
- 窄于 600 px 时，步骤栏只显示编号，说明文字以步骤名称开头。
- 窄于 480 px 时，两个数据堆移到网络上方，类别概率叠放在名称下方。
- 悬停详情只对鼠标显示；触摸时显示同样的图示，但没有详情。
