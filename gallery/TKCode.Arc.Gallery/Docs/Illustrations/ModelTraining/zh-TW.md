## 何時使用

`ModelTraining` 用自動循環的五個步驟說明模型如何學習。一個批次離開訓練資料堆，落入畫在分層底板上的小型網路的輸入層。訊號沿每條連線向前傳遞，得到預測，
輸出層旁的兩個類別機率隨之更新。接著誤差以一小段短線沿連線向後傳回，它經過的每條連線都會變強一點。在各個輪次（epoch）中，批次接連流過：有用的連線變粗並
染上強調色，其餘連線保持淺淡；網路旁的損失曲線逐步下降，損失和輪次讀數同步計數。最後，保留資料在訓練好的模型中跑一遍，分數向上計數，評估達到（或未達到）
目標。其中的網路和數字都是示意性的。

- **AI 產品的到達頁**：一眼看懂訓練、微調或評估。
- **文件與課程**：介紹批次、輪次、損失曲線和保留評估。
- **演講**：不需要旁白，整個故事約二十秒講完。

## 何時不用

- **真實的訓練指標**：插圖播放的是自己的故事。實測損失請用 `LineChart` 繪製，即時任務請用 `TrainingRun` 展示。
- **資料管線**：記錄在系統中流轉時請用 `DataFlow`。
- **可能被當作基準成績的數字**：在插圖旁註明它們只是範例。

## 用法

插圖不需要任何資料：它訓練一個貓狗照片分類器，共十二個輪次，在 90% 的目標下得到 94.2% 的分數。

### 五個步驟

| 步驟 | 發生的事 |
|---|---|
| Batch | 一張資料頁離開訓練資料，落入輸入層，輸入層隨之點亮 |
| Forward pass | 訊號沿每條連線逐層傳遞；類別機率隨之更新 |
| Backward pass | 誤差沿連線傳回；它經過的每條連線都變強一點，損失沿曲線下移 |
| Epochs | 批次接連流過；有用的連線變粗，損失下降，輪次向上計數 |
| Evaluate | 保留資料跑一遍；分數向上計數，勾號變綠 |

圖下方的步驟列可以播放、暫停故事，也可以跳到任一步驟：故事播放時從該步驟繼續，暫停時顯示該步驟的靜止畫面。`GoToStep` 在程式碼中做同樣的事，
`CurrentStep` 表示目前步驟。`Phase`、`Iteration` 和 `CurrentLoss` 跟隨執行進度，每次權重更新後會觸發 `IterationCompleted`，附帶該步驟及其損失。

### 你自己的任務

`ClassNames`、`InputCount`、`HiddenUnits`、`Samples`、`HeldOutSamples`、`BatchSize`、`Epochs`、`LossFrom`、`LossTo`、`Accuracy` 和 `Target`
描述任務；`LossValues` 用平均分布在整個執行過程中的實測值取代曲線。`StepCount` 設定故事展示多少個批次，`Labels` 保存所有文字，包括一個樣本是什麼
（`Unit`）。下面的範例訓練一個垃圾郵件過濾器，它沒有達到目標，因此評估以低於目標結束。

<Demo name="OwnLosses" />

```csharp
card.ClassNames = ["Spam", "Inbox"];
card.Labels = new ModelTrainingLabels { Unit = "emails" };
card.LossValues = [1.12, 0.71, 0.52, 0.44, 0.4, 0.38, 0.37];
card.IterationCompleted += (_, e) => log.Add($"{e.Iteration}: {e.Loss:0.00}");
```

設定 `DefaultStep` 可在故事播放前顯示某個步驟（並從那裡開始播放），`AreControlsVisible` 隱藏步驟列，`IsCaptionVisible` 隱藏說明文字，`Accent`
為訊號、學到的連線、曲線和目前步驟著色。

## 無障礙

- 插圖是一個以 `Title`（"Model training"）命名的群組；圖示是一張影像，其名稱根據類別和數字描述整個執行過程。設定 `Description` 可自行措辭。
- 步驟列是一組按鈕，名稱如 "Step 3 of 5: Backward pass"；播放按鈕名為 Play 或 Pause。
- 說明文字用文字複述目前步驟；讀者選擇步驟或逐步瀏覽故事時，一個禮貌的即時區域會朗讀它。
- 不只依賴顏色：每個讀數都是數字，評估會顯示 Pending、Scoring、Passed 或 Below target，領先的類別顯示其機率。

## 動效

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 批次 | 資料頁沿弧線飛入輸入層，資料堆隨之上移 | 靜止畫面 | 靜止畫面 |
| 前向與反向傳遞 | 圓點沿連線向前，短線沿連線向後；單元點亮並泛起圓環 | 靜止畫面 | 靜止畫面 |
| 權重與損失 | 誤差經過時連線變粗；損失點沿曲線滑動 | 靜止畫面 | 靜止畫面 |
| 評估 | 分數向上計數；標籤交叉淡入並從 0.92 縮放到位 | 立即顯示 | 立即顯示 |
| 懸停 | 滑鼠停在資料堆或某一層上時，故事以彈簧方式減速到 0.6× | 無變化 | 無變化 |

速度為 1 時一次執行約 21 秒，並無縫循環：開頭的 0.8 秒把訓練好的模型還原成未訓練的樣子。一切都是故事時鐘的函式，因此會隨 `Speed` 暫停、單步和縮放。
在減弱動效下，插圖直接開啟已完成的執行，也沒有播放按鈕；選擇一個步驟會顯示它的靜止畫面。

## 響應式

- 從 720 px 起，讀數和損失圖表以 232 px 寬的一欄立在網路旁邊；更窄時位於網路下方。
- 窄於 600 px 時，步驟列只顯示編號，說明文字以步驟名稱開頭。
- 窄於 480 px 時，兩個資料堆移到網路上方，類別機率疊放在名稱下方。
- 懸停詳情只對滑鼠顯示；觸控時顯示同樣的圖示，但沒有詳情。
