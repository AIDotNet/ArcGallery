## 何時使用

`CursorTrailDraw` 是一塊小白板。筆跡以些微的平滑跟隨指標，寬度取自筆壓；滑鼠或手指沒有筆壓時取自速度，所以畫得快的線比較細；每一筆的起筆和收筆都會收尖。抬筆時，隨手畫出的圓、橢圓、方框、正方形、三角形、其他四邊形或直線會彈成工整的圖形，頂端出現一個標籤，可以選擇保留原樣。雷射筆不留下任何內容：它只拖出一小段軌跡，自行變細並淡去，用於講解時指點。

- **設計審查、規劃和教學**：大家快速勾畫方框、流程和圓，並希望它們整齊。
- **現場講解和展示**：講者用雷射筆指點，白板會自己收拾乾淨。
- **到達頁**：讓訪客立刻試用草圖功能。

## 何時不用

- **擷取簽名**：請用 `SignaturePad`，它可以匯出結果。
- **在螢幕截圖或設計稿上加註**：請把留言釘在圖片上。
- **需要選取、文字、圖層或無限畫布的完整繪圖工具**：請用專門的畫布編輯器。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:CursorTrailDraw Label="Release plan sketch" />
</UserControl>
```

`CursorTrailDraw` 位於 Special 套件中；在 `UseArcControls()` 之外再用 `UseArcSpecial()` 註冊。卡片以 `Label` 作為標題並顯示項目數，下方是白板和一條浮動工具列：鋼筆、雷射筆、每種墨水一個按鈕、圖形吸附、復原和清除。白板為 16:10，卡片窄於 560 px 時變為 4:5；為卡片設定 `Height` 時，白板會填滿其餘空間。

白板第一次進入視野且上面什麼都沒有時，會播放一段簡短的草圖（`PlaysIntro`）：一個隨手畫的方框和圓吸附成工整圖形，一條強調色的線把它們連起來，接著雷射筆在圓下方掃過。任何按壓或按鍵都會立即接手。`PlayIntro()` 可以在空白板上再次播放。

### 儲存草圖

`ItemsChanged` 回報每一次變化：一筆落下或吸附成形、一個圖形保留原樣、復原了最後一項，或清除了白板。它的 `Items` 包含所有項目，每項都有識別碼、圖形、墨水、寬度，以及以白板單位表示的中心線點：白板一律寬 1000 個單位，所以儲存的草圖在任何尺寸的白板上都能等比縮放。`SetItems` 載入草圖且不觸發該事件。白板承載實際工作內容時，請關閉 `PlaysIntro`。

<Demo name="Review" />

```xml
<arc:CursorTrailDraw Label="Onboarding screen review" PlaysIntro="False">
    <arc:CursorTrailDraw.Inks>
        <arc:CursorTrailDrawInk Id="ink" Label="Ink" />
        <arc:CursorTrailDrawInk Id="accent" Label="Accent" />
    </arc:CursorTrailDraw.Inks>
</arc:CursorTrailDraw>
```

### 墨水、工具與手感

`Inks` 列出工具列中的墨水，預設選取第一種。沒有設定 `Brush` 時，名為 `accent` 的墨水使用強調色，`red` 使用危險色，其他使用前景色，所以墨水會跟隨主題。沒有設定墨水時，白板提供 Ink、Accent 和 Red 三種。`Tool`、`SelectedInkId` 和 `IsSnapEnabled` 是目前的選擇，都可以雙向繫結。

`PenSize` 是半壓力時的寬度（4 px；筆畫約在 2 到 5 px 之間），`Smoothing` 是筆跡落後於指標的程度（0 為原始，1 為非常平滑），`LaserFade` 是雷射軌跡的留存時間（700 ms），`Speed` 同時加快吸附彈簧、雷射淡出和開場草圖。`AccentBrush` 改變強調色墨水和雷射的顏色；`Hint` 是空白板上的提示文字。`Undo()`、`Clear()` 和 `KeepAsDrawn()` 與工具列和標籤上的按鈕作用相同。

### 最佳做法

**建議**

- 用 `Label` 為白板命名；它既是標題，也是無障礙名稱。
- 從 `ItemsChanged` 儲存項目，再用 `SetItems` 載入。
- 保留兩三種在白板上清楚可辨的墨水。

**避免**

- 在開啟已儲存作品的地方保留開場草圖。
- 指望雷射筆留下痕跡；它只用於指點。

### 常見問題

**哪些圖形會吸附？** 直線（與 0、45、90 度相差 7 度以內時吸附到該角度）、圓和橢圓、矩形和正方形（傾斜 10 度以內時擺正）、三角形和其他四邊形。其他筆畫保持手繪原樣。

**可以取消吸附嗎？** 可以：標籤上的按鈕會沿同一個彈簧把圖形變回原本畫的筆畫。復原則會移除整個項目。

## 無障礙

- 卡片是以 `Label` 命名的群組。白板是可聚焦的繪圖區域（"Label drawing area"），類型描述為白板；它的說明文字解釋按鍵，並列出白板上的內容（"Board contents: 1 circle, 1 line."）。
- 工具列是一個工具列：每個按鈕都是一個 Tab 停駐點，方向鍵、Home 和 End 在按鈕之間移動。工具、墨水和吸附是有具體名稱的切換按鈕；白板為空時，復原和清除呈暗淡狀態。
- 吸附、落筆、復原、清除、工具和墨水的切換以及落筆和抬筆，都會在禮貌型即時區域中播報。標籤上的按鈕是真正的按鈕。
- 繪圖本身不會被朗讀；摘要依圖形列出每一項。

### 鍵盤互動

| 按鍵 | 操作 |
|---|---|
| 方向鍵 | 移動游標（同時按住兩個方向鍵沿對角線移動） |
| `Shift` + 方向鍵 | 慢速移動 |
| `Space` / `Enter` | 落筆、抬筆 |
| `Escape` | 放棄正在畫的筆畫 |
| `P` / `L` | 選擇鋼筆 / 雷射筆 |
| `S` | 開關圖形吸附 |
| `Ctrl` / `Cmd` + `Z` | 復原 |

## 動效

- 筆尖每一影格向指標緩動靠近（預設平滑度下約落後 21 ms）；寬度跟隨筆壓或速度，兩端收尖。
- 抬筆時，被辨識的筆畫會重新取樣，每個點沿一個略帶回彈的彈簧（約 10% 過衝）移到工整圖形上，接著白板換上精確的圖形。保留原樣則沿同一個彈簧變回去。
- 雷射軌跡從頭到尾逐漸變細，並在 `LaserFade` 內淡出；抬筆後它會自行縮短消失。
- 標籤淡入並落到定位，停留約四秒後淡出；被移除的項目會淡出。
- 一個影格迴圈驅動整塊白板；它只在有東西移動時執行，離開視野時暫停。

| 變化 | 完整 | 減弱或暫停 | 關閉 |
|---|---|---|---|
| 開場草圖 | 播放一次 | 直接顯示完成的草圖 | 直接顯示完成的草圖 |
| 吸附 | 彈成圖形 | 立即落定 | 立即落定 |
| 雷射 | 漸隱的軌跡 | 只有圓點 | 只有圓點 |
| 標籤、提示、按鈕 | 淡入淡出和彈簧 | 立即 | 立即 |

## 響應式行為

- 白板在任何尺寸下都寬 1000 個單位，所以項目隨之縮放；新畫的筆跡、工整圖形、游標和格點保持相同的像素大小。
- 窄於 560 px 時，白板變為 4:5，開場草圖改為縱向排列，工具列按鈕縮小到 38 px；窄於 360 px 時縮小到 30 px。
- 觸控只在白板上繪圖，所以頁面仍可在白板周圍捲動。

## 相關元件

- `SignaturePad` 以平滑的筆跡擷取簽名並匯出。
- `InkFluid` 和 `ImageTrail` 是另外兩種會回應指標的平面。

| 元件 | 何時選擇 |
|---|---|
| `CursorTrailDraw` | 大家一邊講解一邊勾畫和指點 |
| `SignaturePad` | 一個人簽名並儲存結果 |
| `InkFluid` | 指標需要攪動裝飾性的背景 |
