## 何时使用

`CursorTrailDraw` 是一块小白板。墨迹以轻微的平滑跟随指针，宽度取自笔压；鼠标或手指没有笔压时取自速度，所以画得快的线更细；每一笔的起笔和收笔都会收尖。抬笔时，粗略画出的圆、椭圆、方框、正方形、三角形、其他四边形或直线会弹成规整的图形，顶部出现一个标签，可以选择保留原样。激光笔不留下任何内容：它只拖出一小段轨迹，自行变细并淡去，用于讲解时指点。

- **设计评审、规划和教学**：人们快速勾画方框、流程和圆，并希望它们整齐。
- **现场讲解和演示**：讲解人用激光笔指点，白板会自己收拾干净。
- **落地页**：让访客立刻试用草图功能。

## 何时不用

- **采集签名**：请用 `SignaturePad`，它可以导出结果。
- **在截图或设计稿上批注**：请把评论钉在图片上。
- **需要选择、文字、图层或无限画布的完整绘图工具**：请用专门的画布编辑器。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:CursorTrailDraw Label="Release plan sketch" />
</UserControl>
```

`CursorTrailDraw` 位于 Special 包中；在 `UseArcControls()` 之外再用 `UseArcSpecial()` 注册。卡片以 `Label` 作为标题并显示条目数，下面是白板和一条浮动工具栏：钢笔、激光笔、每种墨水一个按钮、图形吸附、撤销和清空。白板为 16:10，卡片窄于 560 px 时变为 4:5；给卡片设置 `Height` 时，白板会填满其余空间。

白板第一次进入视野且上面什么都没有时，会播放一段简短的草图（`PlaysIntro`）：一个粗略的方框和圆吸附成规整图形，一条强调色的线把它们连起来，然后激光笔在圆下方扫过。任何按压或按键都会立即接管。`PlayIntro()` 可以在空白板上再次播放。

### 保存草图

`ItemsChanged` 报告每一次变化：一笔落下或吸附成形、一个图形保留原样、撤销了最后一项，或清空了白板。它的 `Items` 包含所有条目，每项都有标识、图形、墨水、宽度，以及以白板单位表示的中心线点：白板始终宽 1000 个单位，所以保存的草图在任何尺寸的白板上都能等比缩放。`SetItems` 载入草图且不触发该事件。白板承载真实工作内容时，请关闭 `PlaysIntro`。

<Demo name="Review" />

```xml
<arc:CursorTrailDraw Label="Onboarding screen review" PlaysIntro="False">
    <arc:CursorTrailDraw.Inks>
        <arc:CursorTrailDrawInk Id="ink" Label="Ink" />
        <arc:CursorTrailDrawInk Id="accent" Label="Accent" />
    </arc:CursorTrailDraw.Inks>
</arc:CursorTrailDraw>
```

### 墨水、工具与手感

`Inks` 列出工具栏中的墨水，默认选中第一种。没有设置 `Brush` 时，名为 `accent` 的墨水使用强调色，`red` 使用危险色，其他使用前景色，所以墨水会跟随主题。没有设置墨水时，白板提供 Ink、Accent 和 Red 三种。`Tool`、`SelectedInkId` 和 `IsSnapEnabled` 是当前的选择，都可以双向绑定。

`PenSize` 是半压力时的宽度（4 px；笔画约在 2 到 5 px 之间），`Smoothing` 是墨迹落后于指针的程度（0 为原始，1 为非常平滑），`LaserFade` 是激光轨迹的存留时间（700 ms），`Speed` 同时加快吸附弹簧、激光淡出和开场草图。`AccentBrush` 改变强调色墨水和激光的颜色；`Hint` 是空白板上的提示文字。`Undo()`、`Clear()` 和 `KeepAsDrawn()` 与工具栏和标签上的按钮作用相同。

### 最佳实践

**建议**

- 用 `Label` 为白板命名；它既是标题，也是无障碍名称。
- 从 `ItemsChanged` 保存条目，再用 `SetItems` 载入。
- 保留两三种在白板上清晰可辨的墨水。

**避免**

- 在打开已保存作品的地方保留开场草图。
- 指望激光笔留下痕迹；它只用于指点。

### 常见问题

**哪些图形会吸附？** 直线（与 0、45、90 度相差 7 度以内时吸附到该角度）、圆和椭圆、矩形和正方形（倾斜 10 度以内时摆正）、三角形和其他四边形。其他笔画保持手绘原样。

**可以撤销吸附吗？** 可以：标签上的按钮会沿同一个弹簧把图形变回原来画的笔画。撤销则会移除整个条目。

## 无障碍

- 卡片是以 `Label` 命名的组。白板是可聚焦的绘图区域（"Label drawing area"），类型描述为白板；它的帮助文本说明按键，并列出白板上的内容（"Board contents: 1 circle, 1 line."）。
- 工具栏是一个工具栏：每个按钮都是一个 Tab 停靠点，方向键、Home 和 End 在按钮之间移动。工具、墨水和吸附是有具体名称的切换按钮；白板为空时，撤销和清空呈暗淡状态。
- 吸附、落笔、撤销、清空、工具和墨水的切换以及落笔和抬笔，都会在礼貌型实时区域中播报。标签上的按钮是真正的按钮。
- 绘图本身不会被朗读；摘要按图形列出每一项。

### 键盘交互

| 按键 | 操作 |
|---|---|
| 方向键 | 移动光标（同时按住两个方向键沿对角线移动） |
| `Shift` + 方向键 | 慢速移动 |
| `Space` / `Enter` | 落笔、抬笔 |
| `Escape` | 放弃正在画的笔画 |
| `P` / `L` | 选择钢笔 / 激光笔 |
| `S` | 开关图形吸附 |
| `Ctrl` / `Cmd` + `Z` | 撤销 |

## 动效

- 笔尖每帧向指针缓动靠近（默认平滑度下约落后 21 ms）；宽度跟随笔压或速度，两端收尖。
- 抬笔时，被识别的笔画会重新采样，每个点沿一个略带回弹的弹簧（约 10% 过冲）移到规整图形上，随后白板换上精确的图形。保留原样则沿同一个弹簧变回去。
- 激光轨迹从头到尾逐渐变细，并在 `LaserFade` 内淡出；抬笔后它会自行缩短消失。
- 标签淡入并落到位，停留约四秒后淡出；被移除的条目会淡出。
- 一个帧循环驱动整块白板；它只在有东西运动时运行，离开视野时暂停。

| 变化 | 完整 | 减弱或暂停 | 关闭 |
|---|---|---|---|
| 开场草图 | 播放一次 | 直接显示完成的草图 | 直接显示完成的草图 |
| 吸附 | 弹成图形 | 立即落定 | 立即落定 |
| 激光 | 渐隐的轨迹 | 只有圆点 | 只有圆点 |
| 标签、提示、按钮 | 淡入淡出和弹簧 | 立即 | 立即 |

## 响应式行为

- 白板在任何尺寸下都宽 1000 个单位，所以条目随之缩放；新画的墨迹、规整图形、光标和网格点保持相同的像素大小。
- 窄于 560 px 时，白板变为 4:5，开场草图改为纵向排列，工具栏按钮缩小到 38 px；窄于 360 px 时缩小到 30 px。
- 触屏只在白板上绘图，所以页面仍可在白板周围滚动。

## 相关组件

- `SignaturePad` 以平滑的墨迹采集签名并导出。
- `InkFluid` 和 `ImageTrail` 是另外两种响应指针的平面。

| 组件 | 何时选择 |
|---|---|
| `CursorTrailDraw` | 人们一边讲解一边勾画和指点 |
| `SignaturePad` | 一个人签名并保存结果 |
| `InkFluid` | 指针需要搅动装饰性的背景 |
