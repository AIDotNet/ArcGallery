## 何时使用

`SplitBar` 在一行里说明一个总量由哪些部分组成，适合放在卡片或仪表盘顶部。每一段的宽度等于它的占比。指针停在某一段上（或用方向键移到
它上面）时，这一段会稍微变宽，较小的段会宽到足以显示自己的名称，其余各段让出位置并变淡；条形上方的读数随即给出它的占比和具体数值。
条形下方的图例可以关掉或重新打开某一段：关掉的段在原处收拢，其余各段展开补满整根条形，百分比数字滚动到新的占比。同一组段换上新数值时，
条形以一次连贯的动画重新分配，因此切换时间段或筛选条件看起来是一次变化，而不是重新绘制。

- **流量或注册来自哪里**：渠道、来源、推广活动。
- **预算与成本**：按类别划分的支出，需要时可以看到具体金额。
- **存储与配额**：按文件类型划分的空间，与磁盘容量对照。
- **问卷答案与构成**：设备、套餐、地区，两到八个类别。

## 何时不用

- **在很多类别之间比较绝对值**：`BarChart` 让每个数值有自己的条形。
- **总量是重点**：`DonutChart` 把总量放在中间；`WaffleChart` 按单位计数。
- **占比随时间的变化**：当每个占比如何变化比当前的构成更重要时，使用随时间变化的堆叠图。
- **一个目标**：`Progress` 进度条比分段条更直接地说明“完成了多少”。

## 用法

按显示顺序添加带有 `Label` 和 `Value` 的 `SplitBarSegment` 项。占比按打开的各段计算；零和负值不占位置。设置 `Unit`（或
`ValuePrefix`、`ValueDecimals` 和 `ValueSuffix`），让读数给出具体数字，而不只是百分比。

```xml
<arc:SplitBar Title="Signups by channel" Description="New accounts on the web app" Unit="signups">
    <arc:SplitBarSegment Label="Newsletter" Value="19670" />
    <arc:SplitBarSegment Label="Partners" Value="12100" />
    <arc:SplitBarSegment Label="Search ads" Value="9350" />
    <arc:SplitBarSegment Label="Unknown" Value="720" />
</arc:SplitBar>
```

前四段使用图表系列颜色；第五段和第六段使用两种中性色，适合 "Other" 这类兜底的部分，所以把它们放在最后。当颜色本身有含义时，给分段设置 `Brush`。

### 新数据

修改同一组分段的 `Value`（或把 `ItemsSource` 绑定到一个集合并就地修改数值），条形会从各条边当前所在的位置重新分配，即使正在移动中也一样。
上面的示例就是这样在一周、一个月和一个季度之间切换的；已关掉的段保持关闭。

```csharp
for (var i = 0; i < values.Length; i++)
{
    Bar.Segments[i].Value = values[i];
}
```

### 关掉某一段

每个图例项都是一个开关。关掉的段显示空心色块、带删除线的名称和 Off 字样；它在条形中不占位置，读数的合计也不包含它。
`SplitBarSegment.IsHidden` 保存这个状态（绑定它可以把筛选条件保留在视图模型中），`HiddenChanged` 报告每一次变化。最后一个打开的段不能关掉：
它的图例项会轻轻晃动，屏幕阅读器会读出原因。

### 高亮与读数

高亮的段由 `HighlightedIndex` 表示（-1 表示没有）；指向某一段或它的图例项会设置它，移开则清除。读数在 `TotalLabel` 加合计与高亮段的颜色、
名称、占比和数值之间切换。点击某一段会触发 `SegmentInvoked`；在获得焦点的条形上按 Enter 或空格键也会触发它，随后如果没有处理程序把它标记为
已处理，就关掉这一段。

### 段内标签与标签行

放得下时，一段在内部显示名称和占比；只放得下占比时只显示占比；否则把标签移到条形下方的标签行，用一条弯曲的引线连到这一段。
标签行里的标签会互相推开，不会重叠。条形宽度每次变化都会重新判断，所以宽卡片上段内显示的标签比手机上多。标签要简短：长名称只有在很宽的段里才放得下。

### 固定的总量

`Total` 大于各段之和时，各段按占这个总量的比例显示，条形其余部分保持空白；图例用 `RemainderLabel` 为它命名（默认为 "Remaining"，设为 null
则不显示），读数会加上 "of" 总量。

## 无障碍

- 条形是一个描述为 split bar 的分组，名称列出每个占比（"Signups by channel: Newsletter 40.8%,
  Partners 25.1%, ... Use the arrow keys to read each share."），后面跟着已关掉的段。
- 在各段之间移动时，会在礼貌的实时区域中读出每一段（"Partners, 25.1%, 12,100 signups."）；关掉或打开某一段也会读出。
- 图例项是开关按钮，名称为对应的段和它的占比，或 "hidden"。关掉的段也会以不带颜色的方式表示：空心色块、带删除线的名称和 Off 字样。
- 条形上的标签、标签行和滚动数字对屏幕阅读器隐藏；条形的名称和读数以文本形式提供同样的数字。每一段都在图例中有名称，所以颜色从来不是唯一的区分方式。

### 键盘

| 按键 | 操作 |
|---|---|
| Tab | 先聚焦条形，再依次聚焦每个图例项 |
| Right / Down | 在条形上：高亮下一个打开的段，让它变宽并读出它（到末尾后回到开头） |
| Left / Up | 在条形上：高亮上一个打开的段 |
| Home / End | 在条形上：高亮第一个或最后一个打开的段 |
| Enter / Space | 在条形上：关掉高亮的段。在图例项上：关掉或重新打开它对应的段 |
| Escape | 清除高亮 |

## 动效

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 新的占比、关掉或打开某一段 | 每条边以弹簧动画移到新位置（约 0.4 秒，无回弹，被打断时保持速度） | 直接跳到 | 直接跳到 |
| 高亮 | 这一段以同样的弹簧变宽；其余各段在 0.2 秒内淡到一半，它的填充色变亮 | 立即 | 立即 |
| 段内标签 | 段变宽或变窄时，名称在占比旁边展开或收起 | 立即 | 立即 |
| 标签行 | 标签滑到新位置并淡入或淡出；标签行平滑地展开和收起 | 立即 | 立即 |
| 百分比、数值、合计 | 数字按变化的方向滚动 | 原地更换 | 原地更换 |
| 读数 | 旧的一行带一点模糊向上退出，新的一行升入 | 直接切换 | 直接切换 |
| 拒绝关掉最后一段 | 图例项晃动 | 不动 | 不动 |

第一次的数据直接显示。帧循环只在有内容移动时运行。

## 响应式

- 条形填满它的宽度并据此安排标签：同样的数据在宽卡片上有更多标签显示在段内，在手机上有更多标签移到标签行。
- 读数位于标题右侧，在窄屏上换到标题下方；图例按需要换成多行。
- 在触屏上，点按某一段会高亮它，点按其他位置会清除高亮。
