## 何時使用

`SplitBar` 在一行裡說明一個總量由哪些部分組成，適合放在卡片或儀表板頂部。每一段的寬度等於它的佔比。指標停在某一段上（或用方向鍵移到
它上面）時，這一段會稍微變寬，較小的段會寬到足以顯示自己的名稱，其餘各段讓出位置並變淡；長條上方的讀數隨即給出它的佔比和具體數值。
長條下方的圖例可以關掉或重新開啟某一段：關掉的段在原處收攏，其餘各段展開補滿整條長條，百分比數字捲動到新的佔比。同一組段換上新數值時，
長條以一次連貫的動畫重新分配，因此切換時間段或篩選條件看起來是一次變化，而不是重新繪製。

- **流量或註冊來自哪裡**：管道、來源、推廣活動。
- **預算與成本**：按類別劃分的支出，需要時可以看到具體金額。
- **儲存與配額**：按檔案類型劃分的空間，與磁碟容量對照。
- **問卷答案與構成**：裝置、方案、地區，兩到八個類別。

## 何時不用

- **在很多類別之間比較絕對值**：`BarChart` 讓每個數值有自己的長條。
- **總量是重點**：`DonutChart` 把總量放在中間；`WaffleChart` 按單位計數。
- **佔比隨時間的變化**：當每個佔比如何變化比目前的構成更重要時，使用隨時間變化的堆疊圖。
- **一個目標**：`Progress` 進度條比分段條更直接地說明「完成了多少」。

## 用法

按顯示順序加入帶有 `Label` 和 `Value` 的 `SplitBarSegment` 項目。佔比按開啟的各段計算；零和負值不佔位置。設定 `Unit`（或
`ValuePrefix`、`ValueDecimals` 和 `ValueSuffix`），讓讀數給出具體數字，而不只是百分比。

```xml
<arc:SplitBar Title="Signups by channel" Description="New accounts on the web app" Unit="signups">
    <arc:SplitBarSegment Label="Newsletter" Value="19670" />
    <arc:SplitBarSegment Label="Partners" Value="12100" />
    <arc:SplitBarSegment Label="Search ads" Value="9350" />
    <arc:SplitBarSegment Label="Unknown" Value="720" />
</arc:SplitBar>
```

前四段使用圖表系列色彩；第五段和第六段使用兩種中性色，適合 "Other" 這類兜底的部分，所以把它們放在最後。當色彩本身有含義時，為分段設定 `Brush`。

### 新資料

修改同一組分段的 `Value`（或把 `ItemsSource` 繫結到一個集合並就地修改數值），長條會從各條邊目前所在的位置重新分配，即使正在移動中也一樣。
上面的範例就是這樣在一週、一個月和一季之間切換的；已關掉的段保持關閉。

```csharp
for (var i = 0; i < values.Length; i++)
{
    Bar.Segments[i].Value = values[i];
}
```

### 關掉某一段

每個圖例項目都是一個開關。關掉的段顯示空心色塊、帶刪除線的名稱和 Off 字樣；它在長條中不佔位置，讀數的合計也不包含它。
`SplitBarSegment.IsHidden` 保存這個狀態（繫結它可以把篩選條件保留在檢視模型中），`HiddenChanged` 回報每一次變化。最後一個開啟的段不能關掉：
它的圖例項目會輕輕晃動，螢幕閱讀器會讀出原因。

### 醒目提示與讀數

醒目提示的段由 `HighlightedIndex` 表示（-1 表示沒有）；指向某一段或它的圖例項目會設定它，移開則清除。讀數在 `TotalLabel` 加合計與醒目提示段的色彩、
名稱、佔比和數值之間切換。點擊某一段會觸發 `SegmentInvoked`；在取得焦點的長條上按 Enter 或空白鍵也會觸發它，隨後如果沒有處理常式把它標記為
已處理，就關掉這一段。

### 段內標籤與標籤列

放得下時，一段在內部顯示名稱和佔比；只放得下佔比時只顯示佔比；否則把標籤移到長條下方的標籤列，用一條彎曲的引線連到這一段。
標籤列裡的標籤會互相推開，不會重疊。長條寬度每次變化都會重新判斷，所以寬卡片上段內顯示的標籤比手機上多。標籤要簡短：長名稱只有在很寬的段裡才放得下。

### 固定的總量

`Total` 大於各段之和時，各段按佔這個總量的比例顯示，長條其餘部分保持空白；圖例用 `RemainderLabel` 為它命名（預設為 "Remaining"，設為 null
則不顯示），讀數會加上 "of" 總量。

## 無障礙

- 長條是一個描述為 split bar 的群組，名稱列出每個佔比（"Signups by channel: Newsletter 40.8%,
  Partners 25.1%, ... Use the arrow keys to read each share."），後面跟著已關掉的段。
- 在各段之間移動時，會在禮貌的即時區域中讀出每一段（"Partners, 25.1%, 12,100 signups."）；關掉或開啟某一段也會讀出。
- 圖例項目是開關按鈕，名稱為對應的段和它的佔比，或 "hidden"。關掉的段也會以不帶色彩的方式表示：空心色塊、帶刪除線的名稱和 Off 字樣。
- 長條上的標籤、標籤列和捲動數字對螢幕閱讀器隱藏；長條的名稱和讀數以文字形式提供同樣的數字。每一段都在圖例中有名稱，所以色彩從來不是唯一的區分方式。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| Tab | 先聚焦長條，再依序聚焦每個圖例項目 |
| Right / Down | 在長條上：醒目提示下一個開啟的段，讓它變寬並讀出它（到結尾後回到開頭） |
| Left / Up | 在長條上：醒目提示上一個開啟的段 |
| Home / End | 在長條上：醒目提示第一個或最後一個開啟的段 |
| Enter / Space | 在長條上：關掉醒目提示的段。在圖例項目上：關掉或重新開啟它對應的段 |
| Escape | 清除醒目提示 |

## 動效

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 新的佔比、關掉或開啟某一段 | 每條邊以彈簧動畫移到新位置（約 0.4 秒，無回彈，被打斷時保持速度） | 直接跳到 | 直接跳到 |
| 醒目提示 | 這一段以同樣的彈簧變寬；其餘各段在 0.2 秒內淡到一半，它的填色變亮 | 立即 | 立即 |
| 段內標籤 | 段變寬或變窄時，名稱在佔比旁邊展開或收起 | 立即 | 立即 |
| 標籤列 | 標籤滑到新位置並淡入或淡出；標籤列平順地展開和收起 | 立即 | 立即 |
| 百分比、數值、合計 | 數字按變化的方向捲動 | 原地更換 | 原地更換 |
| 讀數 | 舊的一行帶一點模糊向上退出，新的一行升入 | 直接切換 | 直接切換 |
| 拒絕關掉最後一段 | 圖例項目晃動 | 不動 | 不動 |

第一次的資料直接顯示。影格迴圈只在有內容移動時執行。

## 響應式

- 長條填滿它的寬度並據此安排標籤：同樣的資料在寬卡片上有更多標籤顯示在段內，在手機上有更多標籤移到標籤列。
- 讀數位於標題右側，在窄螢幕上換到標題下方；圖例按需要換成多行。
- 在觸控螢幕上，點按某一段會醒目提示它，點按其他位置會清除醒目提示。
