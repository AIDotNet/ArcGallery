## 何時使用

`CelebrateButton` 是一個強調色的膠囊按鈕，用來標記值得慶祝的時刻。按下它會執行你的工作：執行期間顯示一個小轉圈和等待文字。成功時，彩紙從按鈕輪廓上的各個點飛出，按鈕向上輕輕一彈，標籤從模糊中浮現為勾號和成功文字，寬度隨之以彈簧過渡到合適的尺寸。失敗時顯示錯誤文字，不放彩紙。幾秒鐘後按鈕回到靜止狀態。

- **完成一個里程碑**：發布網站、發布版本、完成設定、寄出第一張發票。
- **新手引導中的步驟**：一點小小的獎勵，鼓勵使用者繼續下一步。
- **產品展示**：成功的那一刻正是要展示的重點。

## 何時不用

- **日常儲存與表單送出**：使用帶載入狀態的 `Button`。
- **破壞性操作**：使用 `HoldToConfirm` 或 `ConfirmMorph`。
- **密集的工具列與表格**：彩紙需要空間，也會分散注意力。
- **同一視圖裡不只一個**：只有少見，這一下迸發才顯得特別。

## 用法

為按鈕設定靜止時的內容、等待與成功文字，以及要執行的工作。工作是一個 `Func<Task>`：任務執行期間按鈕顯示轉圈和 `PendingLabel`；完成後彩紙迸發，`SuccessLabel` 帶著勾號出現；如果拋出例外，顯示 `ErrorLabel`，再按一次會重新執行工作。沒有設定工作時，按下後直接進入慶祝。每次按鈕接受的按壓，`Click` 與 `Command` 仍然先執行。

```xml
<arc:CelebrateButton x:Name="Ship"
                     Content="Ship release"
                     PendingLabel="Shipping"
                     SuccessLabel="Shipped" />
```

```csharp
Ship.Action = () => releases.ShipAsync(build);
Ship.StatusChanged += (_, e) =>
{
    if (e.NewStatus == CelebrateButtonStatus.Error)
    {
        log.Warn(e.Error);
    }
};
```

`CelebrateButton` 位於 Special 套件中：在 `UseArcControls()` 之外再呼叫 `UseArcSpecial()` 註冊。它高 40 px，寬度為標籤寬度兩側各加 20 px。

### 狀態

| 狀態 | 顯示內容 | 按壓 |
|---|---|---|
| `Idle` | 按鈕的內容 | 執行工作 |
| `Pending` | 轉圈和 `PendingLabel`（未設定時為內容的文字） | 忽略 |
| `Success` | 迸發之後，勾號和 `SuccessLabel`（"Done"） | 忽略 |
| `Error` | `ErrorLabel`（"Try again"），沒有迸發 | 重新執行工作 |

`Status` 是雙向屬性。工作從別處開始時（例如表單送出）可以自己設定它：改為 `Success` 會播放迸發。`StatusChanged` 回報每一次變化，包括自動回到靜止，工作失敗時附帶例外。`ResetAfter`（2.4 秒）是成功或錯誤狀態保持的時長；設為零則一直保持，直到呼叫 `Reset()` 或設定 `Status`。

### 彩紙

每次迸發飛出 44 片（`ParticleCount`），同時最多 180 片，`Cooldown`（1.2 秒）是兩次迸發之間的最短間隔。`Celebrate()` 播放一次迸發而不改變狀態。預設的彩紙以三種色調的強調色為主，配一點明亮的黃色和少量前景墨色，在迸發的那一刻從主題讀取，因此會跟隨強調色與淺色或深色外觀。`ConfettiColors` 以你自己的顏色取代這套配色，各色平均選取。

彩紙最遠飛到按鈕上方 190 px、兩側 150 px、下方 110 px，畫在那裡已有的內容之上。請在按鈕周圍留出這些空間，或者讓容器把它們裁掉。

### 內容準則

- **Content**：用簡短的動詞片語說出這個里程碑："Ship release"、"Launch beta"、"Finish setup"。
- **PendingLabel**：同一個動詞的進行式："Shipping"、"Publishing"。
- **SuccessLabel**：一兩個字的結果："Shipped"、"Published"、"All set"。
- **ErrorLabel**：簡短，同時也是重試的提示："Try again"、"Retry upload"。

### 最佳實務

- 讓 `Action` 回傳真實的任務，等待與錯誤狀態才會如實反映情況。
- 只留給真正的里程碑。每次儲存都迸發一次，就不再有意義。
- 讓各個標籤長度相近，寬度變化就會很小。

## 無障礙

- 它是一個按鈕：Tab 可以聚焦，Enter 或 Space 按下它。它的無障礙名稱是目前顯示的文字（內容、等待文字、成功或錯誤文字），除非設定了 `AutomationProperties.Name`。
- 工作執行期間，按鈕回報為不可用並忽略按壓。
- 一個禮貌型即時區域會播報成功與錯誤文字。
- 成功從不只靠顏色或彩紙表達：勾號和成功文字會取代原來的標籤。
- 彩紙層不接收輸入，對輔助技術隱藏。
- 鍵盤聚焦時在按鈕外 2 px 處繪製 2 px 的膠囊焦點環；指標聚焦不繪製。

### 鍵盤

| 按鍵 | 操作 |
|---|---|
| `Tab` | 將焦點移到按鈕 |
| `Enter` / `Space` | 執行工作（等待中或成功之後忽略） |

## 動態效果

- 按下時按鈕在 100 ms 內縮放到 0.96，放開後恢復。
- 狀態變化時標籤交叉淡化：舊標籤在 150 ms 內淡出，帶 2 px 模糊並漂移 4 px；新標籤在 200 ms 內從同樣的模糊中淡入，並以彈簧落定。等待文字從上方落下，成功文字從下方升起。寬度以臨界阻尼彈簧跟隨。
- 成功時，彩紙飛出的同時按鈕在 130 ms 內彈到 1.07，再用 330 ms 回落。
- 彩紙（彩帶、方塊、圓片和小三角形）從按鈕的圓角輪廓出發，頂邊上的較多，以 260 到 600 px/s 的速度向外並略微向上飛出。它們在 100 ms 內長到完整大小，然後在輕微的重力、空氣阻力和左右飄動下落下。彩帶、方塊和三角形會翻滾，翻轉時沿一個軸壓扁；圓片保持圓形。每一片存在 1.1 到 1.45 秒，並在最後 350 ms 內淡出。
- 所有彩紙由一個圖層在一個影格迴圈中繪製，最後一片淡出後迴圈即停止。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 按下 | 縮放到 0.96 | 無 | 無 |
| 標籤切換 | 淡化、模糊與漂移 | 100 ms 交叉淡化 | 立即 |
| 寬度 | 彈簧 | 立即 | 立即 |
| 成功 | 彩紙與彈跳 | 僅勾號與文字 | 僅勾號與文字 |
| 等待轉圈 | 旋轉 | 靜止並呼吸 | 靜止 |

## 響應式行為

- 按鈕在任何寬度下都保持自己的尺寸，寬度只由標籤決定。
- 在窄螢幕上彩紙會飛到視圖邊緣。請把按鈕放在即使彩紙被裁掉也顯得自然的位置，例如卡片中央。
- 觸控按壓與滑鼠一樣有按下縮放和迸發。

## 相關元件

- `Button`：日常操作，自帶載入狀態。
- `ConfirmMorph`：在原位要求確認的操作。
- `SlideToConfirm`：在付款或轉帳前做出明確的手勢。

| 元件 | 何時選擇 |
|---|---|
| `CelebrateButton` | 完成值得慶祝的事情 |
| `Button` | 日常操作、儲存與送出 |
| `ConfirmMorph` | 與其他操作並排的內嵌確認步驟 |
| `SlideToConfirm` | 重要操作前的明確手勢 |
