## 何时使用

`CelebrateButton` 是一个强调色的胶囊按钮，用来标记值得庆祝的时刻。按下它会运行你的工作：运行期间显示一个小转圈和等待文字。成功时，彩纸从按钮轮廓上的各个点飞出，按钮向上轻轻一弹，标签从模糊中浮现为对勾和成功文字，宽度随之弹簧过渡到合适的尺寸。失败时显示错误文字，不放彩纸。几秒钟后按钮回到静止状态。

- **完成一个里程碑**：发布网站、发布版本、完成设置、发出第一张发票。
- **新手引导中的步骤**：一点小小的奖励，鼓励用户继续下一步。
- **产品演示**：成功的那一刻正是要展示的重点。

## 何时不用

- **日常保存与表单提交**：使用带加载状态的 `Button`。
- **破坏性操作**：使用 `HoldToConfirm` 或 `ConfirmMorph`。
- **密集的工具栏与表格**：彩纸需要空间，也会分散注意力。
- **同一视图里不止一个**：只有少见，这一下迸发才显得特别。

## 用法

为按钮设置静止时的内容、等待与成功文字，以及要运行的工作。工作是一个 `Func<Task>`：任务运行期间按钮显示转圈和 `PendingLabel`；完成后彩纸迸发，`SuccessLabel` 带着对勾出现；如果抛出异常，显示 `ErrorLabel`，再按一次会重新运行工作。没有设置工作时，按下后直接进入庆祝。每次按钮接受的按压，`Click` 与 `Command` 仍然先执行。

```xml
<arc:CelebrateButton x:Name="Ship"
                     Content="Ship release"
                     PendingLabel="Shipping"
                     SuccessLabel="Shipped" />
```

```csharp
Ship.Action = () => releases.ShipAsync(build);
Ship.StatusChanged += (_, e) =>
{
    if (e.NewStatus == CelebrateButtonStatus.Error)
    {
        log.Warn(e.Error);
    }
};
```

`CelebrateButton` 位于 Special 包中：在 `UseArcControls()` 之外再调用 `UseArcSpecial()` 注册。它高 40 px，宽度为标签宽度两侧各加 20 px。

### 状态

| 状态 | 显示内容 | 按压 |
|---|---|---|
| `Idle` | 按钮的内容 | 运行工作 |
| `Pending` | 转圈和 `PendingLabel`（未设置时为内容的文字） | 忽略 |
| `Success` | 迸发之后，对勾和 `SuccessLabel`（"Done"） | 忽略 |
| `Error` | `ErrorLabel`（"Try again"），没有迸发 | 重新运行工作 |

`Status` 是双向属性。工作从别处开始时（例如表单提交）可以自己设置它：改为 `Success` 会播放迸发。`StatusChanged` 报告每一次变化，包括自动回到静止，工作失败时附带异常。`ResetAfter`（2.4 秒）是成功或错误状态保持的时长；设为零则一直保持，直到调用 `Reset()` 或设置 `Status`。

### 彩纸

每次迸发飞出 44 片（`ParticleCount`），同时最多 180 片，`Cooldown`（1.2 秒）是两次迸发之间的最短间隔。`Celebrate()` 播放一次迸发而不改变状态。默认的彩纸以三种色调的强调色为主，配一点明亮的黄色和少量前景墨色，在迸发的那一刻从主题读取，因此会跟随强调色与浅色或深色外观。`ConfettiColors` 用你自己的颜色替换这套配色，各色均匀选取。

彩纸最远飞到按钮上方 190 px、两侧 150 px、下方 110 px，画在那里已有的内容之上。请在按钮周围留出这些空间，或者让容器把它们裁掉。

### 内容准则

- **Content**：用简短的动词短语说出这个里程碑："Ship release"、"Launch beta"、"Finish setup"。
- **PendingLabel**：同一个动词的进行时："Shipping"、"Publishing"。
- **SuccessLabel**：一两个词的结果："Shipped"、"Published"、"All set"。
- **ErrorLabel**：简短，同时也是重试的提示："Try again"、"Retry upload"。

### 最佳实践

- 让 `Action` 返回真实的任务，等待与错误状态才会如实反映情况。
- 只留给真正的里程碑。每次保存都迸发一次，就不再有意义。
- 让各个标签长度相近，宽度变化就会很小。

## 无障碍

- 它是一个按钮：Tab 可以聚焦，Enter 或 Space 按下它。它的无障碍名称是当前显示的文字（内容、等待文字、成功或错误文字），除非设置了 `AutomationProperties.Name`。
- 工作运行期间，按钮报告为不可用并忽略按压。
- 一个礼貌型实时区域会播报成功与错误文字。
- 成功从不只靠颜色或彩纸表达：对勾和成功文字会取代原来的标签。
- 彩纸层不接收输入，对辅助技术隐藏。
- 键盘聚焦时在按钮外 2 px 处绘制 2 px 的胶囊焦点环；指针聚焦不绘制。

### 键盘

| 按键 | 操作 |
|---|---|
| `Tab` | 将焦点移到按钮 |
| `Enter` / `Space` | 运行工作（等待中或成功之后忽略） |

## 动效

- 按下时按钮在 100 ms 内缩放到 0.96，松开后恢复。
- 状态变化时标签交叉淡化：旧标签在 150 ms 内淡出，带 2 px 模糊并漂移 4 px；新标签在 200 ms 内从同样的模糊中淡入，并以弹簧落定。等待文字从上方落下，成功文字从下方升起。宽度以临界阻尼弹簧跟随。
- 成功时，彩纸飞出的同时按钮在 130 ms 内弹到 1.07，再用 330 ms 回落。
- 彩纸（彩带、方块、圆片和小三角形）从按钮的圆角轮廓出发，顶边上的更多，以 260 到 600 px/s 的速度向外并略微向上飞出。它们在 100 ms 内长到完整大小，然后在轻微的重力、空气阻力和左右飘动下落下。彩带、方块和三角形会翻滚，翻转时沿一个轴压扁；圆片保持圆形。每一片在 1.1 到 1.45 秒寿命的最后 350 ms 内淡出。
- 所有彩纸由一个图层在一个帧循环中绘制，最后一片淡出后循环即停止。

| 变化 | 完整 | 减弱 | 关闭 |
|---|---|---|---|
| 按下 | 缩放到 0.96 | 无 | 无 |
| 标签切换 | 淡化、模糊与漂移 | 100 ms 交叉淡化 | 立即 |
| 宽度 | 弹簧 | 立即 | 立即 |
| 成功 | 彩纸与弹跳 | 仅对勾与文字 | 仅对勾与文字 |
| 等待转圈 | 旋转 | 静止并呼吸 | 静止 |

## 响应式行为

- 按钮在任何宽度下都保持自己的尺寸，宽度只由标签决定。
- 在窄屏上彩纸会飞到视图边缘。请把按钮放在即使彩纸被裁掉也显得自然的位置，例如卡片中央。
- 触摸按压与鼠标一样有按下缩放和迸发。

## 相关组件

- `Button`：日常操作，自带加载状态。
- `ConfirmMorph`：在原位要求确认的操作。
- `SlideToConfirm`：在支付或转账前做出明确的手势。

| 组件 | 何时选择 |
|---|---|
| `CelebrateButton` | 完成值得庆祝的事情 |
| `Button` | 日常操作、保存与提交 |
| `ConfirmMorph` | 与其他操作并排的内联确认步骤 |
| `SlideToConfirm` | 重要操作前的明确手势 |
