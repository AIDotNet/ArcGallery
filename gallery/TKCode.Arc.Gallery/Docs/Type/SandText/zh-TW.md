## 何時使用

`SandText` 用細小的方形沙粒畫出一行簡短的大號文字。出現時，沙粒從上方落下，由下往上填滿每個字母。指標在字母中移動會挖出一道溝，並把沙粒沿指標的方向拋出；沙粒翻滾、互相滑落，堆在文字下方。一段時間沒有人再挖之後，字母會重新填滿，散落的沙子一粒一粒消失。給它新的 `Text` 時，舊字母變成下落的沙子，坍成小沙丘，同時新詞倒入。

- **主視覺標題或區段標題**，希望訪客上手玩一玩。
- **隨選擇變化的短詞**，例如旁邊選取的產品名稱、方案或主題。

## 何時不用

- **內文或較長的標題**：只放一行短文字；只需要標題出現時用 `TextReveal`。
- **使用者在附近操作時必須保持可讀的文字**，例如表單標籤或數值：挖掘會把它打散。

## 用法

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:arc="https://github.com/AIDotNet/TKCode.Arc">
    <arc:SandText Text="Mirage" FontSize="72" />
</UserControl>
```

`SandText` 是 Special 套件中的控制項。在 `UseArcControls()` 旁邊用 `UseArcSpecial()` 註冊這個套件。它佔滿給定的寬度，高 1.55 em：字母下方的空間用來堆積沙堆。文字置中；放不下時縮小到寬度的 94 %，所以長詞在手機上也能完整顯示。

### 尺寸與文字

用 `FontSize` 設定固定字級，或用 `FontSizeRatio` 依控制項寬度決定字母大小（預覽用 `0.18`，標題隨卡片一起放大縮小）。修改 `Text` 會讓舊字母落下、新字母倒入；已經落在新字母位置上的沙粒保持不動。

### 沙粒與挖掘

`GrainSize` 是一粒沙的邊長（2 px）。`DigRadius` 是指標周圍被挖開的範圍（14 px），`IsDigEnabled` 可以關閉挖掘。沙粒使用文字顏色（`Foreground`，預設是強調色），每一粒都會稍微變亮或變暗；`Palette` 可以改為提供一組顏色讓沙粒從中挑選：

```csharp
sand.Palette = [Color.Parse("#E8B04B"), Color.Parse("#D9893A"), Color.Parse("#F2D49B")];
```

### 用程式碼控制

`IsDissolved` 讓字母散開：所有沙粒落下並消失；把它設回 false 會重新倒入字母。`Dissolve()`、`Gather()` 和 `Toggle()` 在程式碼中做同樣的事。最後一粒沙消失時觸發 `Dissolved`，一次倒入之後字母重新完整時觸發 `Gathered`（首次顯示、新文字、`Gather()` 或自動修復）。

### 最佳實務

**建議**

- 文字只放一個短詞或短語，並給它足夠的空間：字母至少 40 px，沙粒才看得清楚。
- 讓控制項佔滿整列寬度，字母下方才有堆沙的空間。

**避免**

- 同一個畫面放好幾個沙粒標題；一個讓人想玩，多了就成了雜訊。
- 依賴沙粒傳達任何資訊：輔助技術讀取的是文字本身。

### 常見問題

**挖掘會改變文字嗎？** 不會。挖掘只移動沙粒；文字、它的無障礙名稱和標題層級都不變，字母會自己修復。

**為什麼小字看起來很粗糙？** 無論字級多大，一粒沙都是 `GrainSize` px，所以小字的每個字母沙粒較少。請用更大的字，或更小的 `GrainSize`。

## 無障礙

- 文字以標題的形式公開（預設第 2 層，由 `HeadingLevel` 設定；0 表示一般文字），名稱就是 `Text`，所以無論沙粒在做什麼，螢幕閱讀器和搜尋都把它當作文字讀取。
- 沙粒只是裝飾，從不改變無障礙文字。
- 控制項不取得鍵盤焦點，也沒有鍵盤互動：它是一個標題，不是需要操作的控制項。

## 動效

- 首次顯示時，字母在約一秒內倒入：沙粒在重力作用下從頂部落下，直接穿過自己格子上方的沙子，最下面的列最先填滿。
- 新的 `Text` 讓舊字母以整塊的形狀每格畫面下落兩列沙粒，滑落成 45° 的沙丘，同時新詞在約 0.75 s 內倒入。
- 被挖出的沙粒帶著指標的一部分速度飛出，然後像其他沙子一樣下落、滑動。最後一次挖出沙粒約 0.7 s 後字母開始修復，字母外的散沙在約兩秒內消失。
- 每粒沙移動時保持自己的色調。只在有東西移動時才逐格繪製，控制項不在視野中時暫停。

| 變化 | 完整 | 減弱 | 關閉 |
|---|---|---|---|
| 首次顯示 | 沙粒倒入 | 字母直接成形 | 字母直接成形 |
| 新的 `Text` | 舊字母坍落，新字母倒入 | 立即替換 | 立即替換 |
| 指標在字母上 | 挖掘 | 無變化 | 無變化 |
| `Dissolve()` / `Gather()` | 沙子落下消失 / 重新倒入 | 立即完成 | 立即完成 |

## 響應式行為

- 控制項與父層等寬、高 1.55 em；設定 `FontSizeRatio` 時字母隨寬度變化，寬於 94 % 寬度的文字會縮小到放得下，所以標題在手機寬度下也能用。
- 改變尺寸會重建網格，字母直接以成形的樣子顯示。
- 在觸控螢幕上用手指拖曳會挖掘；手指輕點不做其他事。

## 相關元件

- `TextReveal` 在捲動進入視野時讓標題出現。
- `TextMorph` 把一個標籤變成另一個標籤，不把它拆散。

| 元件 | 何時選擇 |
|---|---|
| `SandText` | 標題應當好玩、可以被拆散 |
| `TextReveal` | 標題應當出現，然後保持不動 |
| `TextMorph` | 一個短標籤變成新的標籤 |
